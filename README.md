# 🍿 Кино на вечер

PWA для выбора фильма вдвоём: колода карточек со свайпами, ваши списки, совпадения и рулетка.
Ставится на iPhone через Safari → «Поделиться» → «На экран Домой».

## Разделы

| Вкладка | Что там |
|---|---|
| **Свайпы** | Колода фильмов: вправо «хочу», влево «нет». Подборки: популярное, топ-250, про любовь, семейное, свой фильтр (жанр, рейтинг, год). То, что предложил партнёр, всегда идёт первым. ↺ отменяет последний свайп. Тап по карточке открывает подробности. |
| **Мои** | Что хочу посмотреть я. |
| **Её** (имя партнёра) | Что хочет она. Метка «оцени» стоит на фильмах, которые ты ещё не видел в колоде. |
| **Общие** | Совпадения: оба лайкнули. Сверху рулетка «Выбери за нас» с фильтром по времени. |
| **Список** | «Наш список»: всё, что интересно хотя бы одному. «Поиск»: найти любой фильм и добавить «+». «Просмотрено»: история с оценками обоих. |

## Демо-режим

Пока `js/config.js` пустой, приложение работает локально: встроенные фильмы без постеров и имитация партнёра.
Запуск на компьютере:

```bash
python3 -m http.server 5178
```

Дальше открыть http://localhost:5178.

## Настройка (один раз, ~15 минут)

### 1. Токен Кинопоиска
1. Зарегистрироваться на https://kinopoiskapiunofficial.tech.
2. В профиле скопировать API-ключ (бесплатно, 500 запросов в сутки; подборки кэшируются на сутки).
3. Вставить в `js/config.js` → `KP_API_KEY`.

### 2. База Supabase
1. https://supabase.com → New project (бесплатный план, регион — Frankfurt).
2. **SQL Editor** → New query → вставить весь `supabase/schema.sql` → **Run**.
3. **Project Settings → API**: скопировать `Project URL` и `anon public` key в `js/config.js`.

> Supabase в России в разное время работал нестабильно. Если с телефона без VPN не подключается, напиши, и переедем на другой бэкенд.

### 3. Хостинг (нужен HTTPS)
Самое простое — **GitHub Pages**:
1. Создать репозиторий и залить туда содержимое этой папки.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

Подойдёт и Netlify Drop (https://app.netlify.com/drop): просто перетащить папку.

### 4. Установка на iPhone
1. Открыть ссылку в **Safari** → «Поделиться» → «На экран Домой».
2. Запустить с иконки, ввести имя → «Создать нашу пару».
3. Шестерёнка → «Поделиться приглашением» → отправить ей.
4. Она открывает ссылку в Safari, добавляет на экран «Домой», вводит имя и код (код подставится сам, если открыть ссылку) → «Я новый участник».

Сменили телефон? Вводите тот же код пары и выбирайте «Я — <имя>»: все данные останутся.

## Безопасность
Логинов нет: доступ к данным пары даёт код из 8 символов. Для личного использования этого достаточно, но код лучше никому не показывать.
Ключи в `config.js` видны любому, кто откроет сайт. Anon-ключ Supabase на это и рассчитан, а ключ Кинопоиска бесплатный и ограничен только лимитом запросов.

## Структура
```
index.html             оболочка
css/style.css          стили
js/app.js              интерфейс: вкладки, свайпы, шторки, рулетка, онбординг
js/api.js              Кинопоиск + демо-набор
js/store.js            Supabase / localStorage, realtime
js/config.js           ключи
sw.js                  офлайн-кэш и кэш постеров
supabase/schema.sql    схема БД
```

После изменения файлов поднимай `VERSION` в `sw.js`, чтобы телефоны быстрее получили обновление.
